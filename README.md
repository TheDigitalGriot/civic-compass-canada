# Springdale Civic Compass

Source-grounded civic research and discussion for Springdale, Brampton. Includes 47 candidates across seven contests, a municipal map, candidate portraits, policy matrix, history timelines, and evidence connection views.

## GitHub Pages

In Settings → Pages, select Deploy from a branch, branch main, folder /docs, then Save. No build or installation is required. All app assets are local and use relative paths.

## Verification

Run `node --test tests/*.test.mjs`. Serve docs/ with a static HTTP server for local development.

## Evidence and privacy

Research is partial and date-stamped. Sources and limitations appear in the app. No ideology score, ranking or recommendation is computed. Board eligibility and district require official confirmation. Notes are browser-local and temporary by default. No saved sessions, credentials or hosting identifiers are part of this repository.
